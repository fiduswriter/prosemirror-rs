prosemirror-rs Demos

These demos show prosemirror-rs running in the browser via WebAssembly, acting as a drop-in replacement for prosemirror-model and prosemirror-transform.

The bundler (Rspack) is configured to alias the original packages to prosemirror-rs so that all downstream ProseMirror packages automatically use the Rust implementation.

  • Basic Editor

    A simple rich-text editor with formatting, lists, and history.
  • Advanced Editor

    Two side-by-side editors with simulated real-time collaboration and tables.
